# ADR 2 • 소유권·차량·참여자 세션
차량에서 만든 여행은 DRAFT다. 보유자가 보는 일회용 소유권 QR과 동승자에게 보여주는 초대 QR을 구분한다. 관리자가 소유권 QR로 참여하면 ACTIVE가 된다. 민감한 QR은 따로 표시하며 URL fragment에만 넣고 가입 후 주소에서 제거한다. 초대 또는 소유권 URL만으로 인증 API를 호출할 수 없다.
서버는 무작위 256비트 토큰의 SHA-256만 보관한다. 초대와 차량 세션은 7일, 멤버 쿠키는 30일, 차량 연결 QR은 120초다. 차량 계정 전환은 회원 쿠키를 가진 휴대폰이 일회용 QR에 확인 응답을 보내야 한다. 차량 투표는 서버에서 해당 차량의 현재 member_id에 기록하고 화면에 표시된 member_id와 다르면 409로 거부한다. APK 사설 저장소에 여행별 차량 세션을 보관하며 앱 백업은 비활성화한다.
모바일은 같은 출처 쿠키를 사용하고 Android는 차량 Bearer 토큰을 사용한다. 모바일은 WebSocket revision 알림과 5초 REST 재조회, 차량은 4초 REST 조회를 사용한다. 별도 메시지 브로커 없이 SQLite 커밋을 기준으로 동작한다. 기존 웹/차량 UI와 독립 빌드 구조를 유지했다.
현재 관리자 소유권은 익명 사용자 행과 휴대폰 쿠키에 귀속된다. 기기나 쿠키를 잃었을 때의 계정 복구, 장기 재발급 및 외부 공개 서비스의 차량 등록 정책은 후속 과제다.
