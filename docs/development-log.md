## 2026-11-14 차량 오프라인 지도와 모바일 참여 화면

Compose 지도는 APK의 2021 경계와 2026-07-01 카탈로그를 읽는다. 여행 세션 없이 전국·지역 지도를 열 수 있고, 전국에는 장소 핀이 없다. 방문 후보를 확인된 장소 수에서 제외한다. 여행일지 스냅샷과 차량 사진 미리보기는 서버·여행·인증 정보별로 구분한다. 모바일 참여 폼의 제목, 입력 간격, 초점 및 오류 표시를 조정했다.

기존 데모 APK의 API 포트 18083은 호스트와 AVD 양쪽에서 health 200이었다. QR HTTPS 포트 19446은 연결 거부였고 로컬 HTTPS 웹과 기존 API 프록시를 연결한 뒤 페이지와 health를 확인했다. trippick.test는 테스트 호스트 설정과 인증서가 필요하다.

별도 앱 ID·포트·임시 DB에서 Pleos SDK APK를 검사했다. 서버 없는 새 설치에서 전국→통합 지역, QR 판독, 네 참여자의 업로드·재시도, 좋아요 동기화, 차량 앨범 확정과 네 원본 다운로드, 충남 장소 및 연결 사진을 확인했다. 서버 종료 뒤 저장 장소, 앱 프로세스 재시작 뒤 캐시된 사진, Drive 조작 차단과 Park 복원을 확인했다. Android 단위 5개·모바일 2개·백엔드 11개 통과. 수동 방문 fixture를 사용했고 실제 내비 도착, 실차와 실물 휴대폰은 미실행이다.
