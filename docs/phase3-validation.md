## 실제 데이터와 시험 데이터

실제 목적지 조회 응답에서는 저장 가능한 목적지를 확인하지 못했다. 별도 시험 앱의 공식 경로 요청이 반환됐지만 onDestinationChanged 또는 도착 콜백은 관측되지 않았다. 현재 위치는 방문 후보이며 도착 증거로 승격하지 않는다. 도착 응답에는 좌표가 없어 앞선 목적지 정보와 연결할 수 있을 때만 처리한다. 출발 시각은 근거가 있을 때 입력한다. MOCK은 기본 비활성화이며 MANUAL, NAVIGATION, LOCATION과 출처를 구분한다.

공식 Virtual Console의 주행 제한 전환, HOME 직후 3초, 강제 종료, 재부팅을 시험했다. 강제 종료·재부팅 직후 앱 프로세스가 없었고, 명시적으로 실행한 뒤 여행 복원과 SDK 재연결을 확인했다. 지속적인 백그라운드 수집은 지원하지 않는다.

## 회귀 및 성능

- 백엔드 9건 통과. 복구·접근 격리, 동시 투표와 취소, 앨범 확정 충돌, 재접속, EXIF, 충남·충북·대전 판정과 수동 연결을 포함한다. 웹 단위 검사 2건 및 배포 빌드 통과. 기본·Pleos 디버그 APK 모두 빌드와 단위 검사 통과.
- 500장 메타데이터를 13페이지, 71,785바이트로 읽었다. 로컬 측정 21.4ms이며 실제 모바일 네트워크의 로딩 시간과 구분한다. 초기 조회와 revision 변경 시 메타데이터 전 페이지를 다시 읽는다.
- 전용 AVD와 로컬 HTTPS Chrome 세션 4개로 QR 해독, 참가, 사진 업로드, 좋아요 동기화, 차량 계정 연결, 앱 재기동, 차량 앨범 확정, 네 브라우저의 PNG 다운로드, 충남 핀에서 공유 사진 열람까지 통과한 실행을 확보했다. 최종본 생명주기 시험에서는 재부팅 후 기록 활성 상태까지 복원했다.
- 재현 진입점은 tests/integration/pleos_album.py이며 전용 AVD, 로컬 서버, Chrome과 테스트용 TLS 설정에서 TRIPPICK_TEST_LOOPBACK=1 및 TRIPPICK_TEST_JOURNAL=1을 사용한다. 개인 단말과 실차는 시험 범위에 포함되지 않았다.

## 지도 데이터와 남은 검증

geoBoundaries gbOpen 대한민국 ADM1 2021판의 17개 실제 경계를 사용한다. Natural Earth 원자료와 배포물의 라이선스·고정 버전은 assets/maps/SOURCE.md에 기록했다. 군위군 대구 편입 등 이후 변경은 반영되지 않으며, 시군구는 제공된 코드만 저장한다. 우선순위는 내비 모의 주행 또는 실차에서 목적지 변경·도착 검증, 최신 행정경계 검증, 실제 모바일 브라우저와 차량 화면 크기별 사용성 검증 순이다.

### 최종 APK 재실행 결과
마지막 두 통합 실행 모두 여행 생성, 네 브라우저의 업로드·동기화, 충남 장소 연결과 모바일 핀 열람까지 성공했다. 재부팅을 포함한 첫 실행은 계정 연결 QR을 닫으려는 시점에 지도 화면을 만나 중단됐다. 다음 실행은 계정 연결과 좋아요 취소·재투표 이후 강제 종료·재실행 단계에서 UI 트리에 ‘목록’ 버튼이 나타나지 않아 중단됐다. 이후 dumpsys에서 TripPick이 전면 Activity인 점을 확인했으나 원인을 특정하지 못했다. 따라서 앞선 전체 통과 실행과 별도로 최종 APK의 앨범 확정·네 기기 다운로드 회귀는 검증 보류다. 최종 지도 화면의 공식 폼 팩터별 시각 검수도 남아 있다. 다음 개발 전 두 재기동 경로의 재현과 해소를 먼저 진행한다.
