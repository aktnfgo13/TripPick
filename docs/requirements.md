# TripPick 범위
Phase 1의 사용자 동작은 차량 앱 시작, 웹에서 서버 준비 상태 조회, 서버 재시작 후 로컬 저장소 재사용까지다. Phase 2에서 관리자가 휴대폰으로 소유권을 확보하고 참여자가 QR로 가입해 직접 선택한 사진만 업로드한다. JPEG/PNG부터 지원하고 HEIC 디코더가 없으면 변환 방법을 안내한다. 차량에는 미리보기만 전달한다.
여행은 여러 날에 걸친다. DRAFT → ACTIVE → REVIEW → PUBLISHED 전이는 관리자 명령이다. 목적지 도착은 방문 후보 하나를 추가한다. 차량의 투표에는 명시적으로 연결된 참여자의 신원이 필요하다. 관리자는 좋아요와 별도로 앨범 항목과 순서·표지를 확정한다.
Phase 3 전국 화면은 17개 시·도 경계와 기록 유무만 표시한다. 지역 화면은 해당 지역의 장소별 핀, 사진, 일지를 연결한다. 경계 데이터 출처·라이선스 확인 후 도입한다. 내비·차량 위치·EXIF 시간과 GPS가 충돌하면 출처·신뢰도를 보존하고 확인 대기로 둔다.
Phase 4는 OpenCV 선명도와 지각 해시 기반 규칙 분석이다. 점수·유사 그룹을 제안하고 원본은 보존한다.

Phase 2의 범위는 사진을 직접 선택해 공유하고 차와 휴대폰에서 같은 투표·앨범을 보는 흐름이다. 실제 지원 포맷은 JPEG·PNG이며 HEIC는 서버 디코더의 등록 확장자 검사 결과 지원하지 않는다. 업로드는 파일당 12 MiB, 3200만 픽셀, 여행당 원본 합계 512 MiB까지다. 앱 동작 및 검증 범위는 phase2-validation.md에 기록한다.
